## 🪟 Windows Setup Walkthrough

Follow these steps in order. Take your time, and keep the setup window open until it tells you the process is complete.

1. Open your web browser.
2. Go to the download link in the Download talorys section above.
3. Visit this link to download the application.
4. Complete the download action shown on the page.
5. When the download finishes, open the Start menu on Windows.
6. Type Command Prompt in the Start menu search box.
7. Open Command Prompt from the results.
8. In the Command Prompt window, type the setup command: npx create-talorys@latest
9. Press Enter.
10. Follow the on-screen prompts. The setup may ask you to sign in to Cloudflare and may ask you to confirm where your assistant should live.
11. Wait while talorys prepares your personal assistant.
12. When setup finishes, open the web address shown in the Command Prompt window in your browser.

That web address is your talorys assistant. You can bookmark it so you can return to it later. If you close Command Prompt, your assistant does not disappear. It continues to run in your Cloudflare account.

## ✨ What You Can Do

talorys is designed to be useful every day without adding clutter. The main areas are chat, memory, tasks, notes, and scheduled reminders.

### 💬 Chat With Your Assistant

Use chat to ask questions, think through ideas, or get help with everyday planning. Your assistant can use the context you have stored in talorys, such as notes and tasks, to give more useful responses. You do not need to repeat everything each time you open the app.

### 🧠 Memory That Helps You Stay Organized

Memory is for details you want your assistant to remember. You might save preferences, recurring instructions, project context, or personal reminders. Because talorys is single-user, memory is built around you and your own workflow.

### ✅ Tasks and To-Dos

Keep a simple list of tasks inside talorys. Add items, review what is pending, and use your assistant to help you decide what to do next. Tasks are useful for both small errands and longer personal projects.

### 📝 Notes

Notes give you a place to store information you want to keep nearby. Use notes for ideas, reference details, shopping lists, planning notes, or anything you want your assistant to help you revisit.

### ⏰ Scheduled Reminders

Scheduled reminders help you keep track of things that need attention later. Set a reminder, and talorys can help you stay aware of it. This is useful for recurring personal routines, follow-ups, and time-based tasks.

## 🔒 Privacy and Ownership

talorys is built around ownership. Your assistant runs in your own Cloudflare account. It is not a shared public service, and it is not designed for multiple users.

The project is free-tier friendly. That means it is intended to work within Cloudflare’s free-tier-friendly setup for a single user. It does not include telemetry, so there is no built-in tracking report sending your activity to the project.

You remain responsible for your Cloudflare account and the access you grant during setup. Keep your sign-in details private, and use a password manager if you have one. Because talorys is single-user, you do not need to create team roles or manage other people’s permissions.

## 🛠️ Everyday Use

After setup, open your talorys web address in your browser. The interface is organized around the main parts of your assistant: chat, memory, tasks, notes, and reminders.

A simple routine looks like this:

1. Open talorys in your browser.
2. Start a chat with your assistant.
3. Add a task or note when something comes up.
4. Save important details to memory when you want your assistant to remember them.
5. Set a reminder for anything that needs attention later.
6. Return to talorys whenever you need to review your tasks, notes, or reminders.

You can use talorys as often or as little as you like. It is your personal assistant, so it should fit your routine rather than create extra work.

## ❓ Troubleshooting

If the download page does not open, copy the link and paste it into a fresh browser tab.

If the setup command does not start, close Command Prompt and open it again, then type the command exactly as shown: npx create-talorys@latest

If setup asks you to sign in to Cloudflare, complete the sign-in in the browser window that appears, then return to Command Prompt and continue.

If you close Command Prompt during setup, open Command Prompt again and run the setup command once more.

If you lose the web address for your assistant, sign in to your Cloudflare account and look for the talorys setup created during the process.

If the assistant does not load in your browser, wait a moment and refresh the page. Setup can take a short time to finish preparing the account.
